RADIMCOM - SDR receiver in the web browser
==========================================

Features
--------
- Up to 4 VFOs (A-D) side by side, each with its own SDR: RTL-SDR dongles, LimeSDR Mini and Airspy R2.
  Fewer SDRs: the remaining VFO windows stay in place, greyed out ("NO SDR").
- VFO chaining: one dongle can serve several VFOs (e.g. one dongle for VFO A-D, or two
  dongles with two VFOs each); a chained VFO listens inside the band of its dongle.
- Transceiver-style screen: S-meter, 7-segment frequency displays, spectrum and waterfall
  (zoom 1x-32x), frequency shown on mouse hover, tuning by click, drag and mouse wheel.
- Modes AM, FM, WFM, LSB, USB, CW with adjustable filter width (drag the filter edge).
- WFM stereo and RDS (station name, RadioText, PI, PTY, clock).
- HF through an upconverter (configurable LO), warning when the manual CONV/BYPASS switch
  has to be changed.
- Squelch per mode, RF gain slider under each display (or AGC), audio ALC, automatic notch.
- AFI: audio frequency inversion (voice inversion scrambler / descrambler), frequency in SET.
- LPF and HPF: audio low-pass and high-pass filter, frequency by mouse wheel over the key or in SET.
- CUE: keep listening to other VFOs at a separate CUE level while one VFO is selected;
  MAIN and CUE volume faders, stereo level meter, MUTE.
- REC and REC SQ: record the audio of the selected VFO to MP3 files in data\recordings:
  everything, or only while the squelch is open. RECS: the RECORDINGS tab lists the files and
  plays them in the browser.
- Decoders: FT8, WEFAX (radio fax), CW (Morse), RTTY (auto shift/speed), SSTV (14 modes),
  PACKET (AX.25 1200 / 9600 Bd, APRS with a station list and map), POCSAG (pagers, 512 / 1200 / 2400 Bd), ACARS (aircraft data link, VHF airband), CPDLC (controller-pilot messages in ACARS);
  optional daily log for each.
- DSD mode (first test version): digital voice (DMR, P25, D-Star, YSF, NXDN, dPMR, M17...) with call list;
  needs DSD-FME, which is not in the package: run install_dsd.bat (read its patent notice first).
- DAB / DAB+ digital radio (Band III): station list, DLS text, slideshow (via welle-cli).
- VDL2 (aircraft data link, via dumpvdl2): EU or US channels, all channels of the region at once.
- ISM decoder: devices on 433 and 868 MHz, such as weather sensors (via rtl_433).
- Satellite tracking in the SATELLITES tab: passes, world map, Doppler correction of the receiver
  and a K3NG antenna rotor over USB.
- Remove DC peak and remove spurs from local sources.
- Band buttons (HF/VHF/UHF ham, broadcast, airband, marine, PMR446, CB) and frequency
  memories with groups and favourites (import from SDR#).
- Frequency correction (ppm), bias-tee, sample rate, waterfall colours, S-meter calibration.
- TX with LimeSDR (optional, off by default, licence required): PTT = hold SPACE, FM test
  message or carrier; only in ham bands, CB 27 MHz and PMR446.
- Clock (local / UTC), all settings remembered per VFO.

Installation on a new PC (setup, recommended)
---------------------------------------------
1. Connect the SDR dongles (RTL-SDR, LimeSDR Mini, Airspy R2).
2. Run RADIMCOM_Setup_v<version>.exe (from the release page). No Python and no administrator rights needed;
   Windows SmartScreen may say "Windows protected your PC": More info -> Run anyway (the setup is not signed).
   - Folder: C:\RADIMCOM by default (an older zip installation there is upgraded in place, data\ stays).
   - Tick the USB drivers you need (Zadig for RTL-SDR, FTDI D3XX for LimeSDR - see DRIVERS.txt; they ask for
     administrator rights), optionally DSD-FME (DSD mode, patent notice) and starting with Windows.
   - At the end it opens the SDR setup in the RADIMCOM window (assign the dongles to VFO A-D; IDENTIFY finds
     the dongle you unplug) and then starts RADIMCOM.
3. RADIMCOM opens in its own window (RADIMCOM.exe; pin it to the taskbar if you like). Closing the window keeps
   the receiver running in the tray (icon by the clock); right click it -> Exit RADIMCOM to stop it.
Upgrade: close RADIMCOM and run the setup of the new version into the same folder; data\ and DSD-FME stay.
  The page tells when a new version is out (with a link to its setup).
Upgrade from 0.114 or older (installed from a zip): run the setup and install into the folder of the old
  installation (e.g. C:\RADIMCOM). The setup says on its first page that it upgrades the older RADIMCOM;
  data\ stays, .venv and the upgrade scripts are removed, RADIMCOM becomes the app (RADIMCOM.exe).
Uninstall: Windows Settings -> Apps -> RADIMCOM (asks whether to delete data\ as well).

Different dongles later: close the receiver and run "RADIMCOM SDR setup" (setup.bat) again.
Old settings are moved to data\config_backup\.

All settings, memories, logs and saved images of this PC are kept in the data\ folder.

Transmitting (LimeSDR only): SET -> "Enable TX" (off by default). PTT = hold SPACE.
TX works only in ham 160-10 m, 6 m, 4 m, 2 m, 70 cm, 23 cm, CB 27 MHz and PMR446.

Ver. 0.115beta1
(test beta, GitHub branch 0.115beta1)
Extra: setup instead of ZIP - easier installation and upgrades
- Until 0.114 RADIMCOM was a ZIP: install.bat needed Python on the PC, created .venv and downloaded about
  60 MB of Python packages from the internet - the most common source of problems.
- Now one file, RADIMCOM_Setup_v<version>.exe: Python and all packages inside, nothing to download,
  works offline, no administrator rights; drivers, DSD-FME, shortcut and autostart as check boxes.
- Upgrade = run the newer setup into the same folder; data\ stays. Also for a ZIP installation of 0.114 or older.
Main Features
- POCSAG pager decoder (by Brano, brjanicek; DECODERS tab, page POCSAG): 512, 1200 and 2400 Bd at once,
  both polarities, from the baseband (any mode and filter). One or two wrong bits per codeword are corrected,
  a codeword that cannot be corrected is a red ? in its message. Numeric or alphanumeric is guessed from the
  function bits and the characters (the other reading in the tooltip). MESSAGES and ADDRESSES (newest message of
  each RIC) views, filter (click on a RIC), NO TONE, daily log data\logs\pocsag_YYYY-MM-DD.txt (LOG).
- FT8 station map: next to the FT8 table a map of the stations heard (triangle at the locator from their
  messages; green = CQ, cyan = QSO), time window 10 min / 30 min / 1 h / 12 h / 24 h, CLR, list of the
  stations with locator, distance, SNR and age on the right; popup with azimuth, message, QRZ and PSK Reporter.
  Opens also in a new tab. The server keeps the stations of the last 24 h (not over a restart).
- ISM at 868 MHz: Wireless M-Bus meters, weaker sensors (by Brano, brjanicek). The 868.30 preset now has two
  rtl_433 channels of 256 kS/s: 868.30 (LaCrosse, Bresser...) and 868.95 MHz (Wireless M-Bus T1 / C1 meters,
  e.g. heat cost allocators in a block of flats), both with -Y autolevel (finds the weaker FSK devices; off at
  433 MHz OOK, where it only added false decodes). Live about 105 messages a minute instead of 10.
  Rate and autolevel are set per channel; the counter tooltip shows the channels and their rates.
  - Fewer rows: a wM-Bus meter is one row for an hour with its latest message (mostly encrypted, shown
    compactly); the same message of any device within 1 min joins its row (xN) and the row moves to the top;
    the list keeps 500 rows.
  - Two decoders, one packet: names learnt from one packet also join later packets read by only one decoder
    (same channel and device ID only, never a wM-Bus meter).
  - RAW at FSK: a package at the frequency (+-10 kHz) of a decoded one at the same time is not shown as RAW.
- ISM page redesigned: views MESSAGES | DEVICES | TIMELINE.
  - DEVICES: a card per device with large values (temperature, humidity, wind compass...), a 24 h curve of
    temperature and humidity, battery, signal bars, age and interval of its messages; quiet devices fade.
  - TIMELINE: a dot for each message of each device (1 h) or a block per 5 minutes (6 h / 24 h).
  - 1 h / 6 h / 24 h in the header for DEVICES, TIMELINE and the device tab.
  - A click on a card opens the device's tab: its details and a chart of every value it sends over
    1 h / 6 h / 24 h (temperature, humidity, wind, rain...), signal (RSSI / SNR) and messages per interval.
    One cursor for all charts, drag to zoom all of them in, double click back (uPlot charts).
  - Names, pins and hiding on the cards (data\ism_devices.json, all VFOs); NEW badge for a device never heard
    on this PC in 60 days (data\ism_known.json).
  - Category chips (weather, TPMS, remotes, security, alarms, meters, other, RAW) and a filter for all views;
    messages per minute, devices and top models. Rows flash on a new message, CRC check mark, a picture of the pulses in RAW rows.
- Windows setup RADIMCOM_Setup_v<version>.exe: its own Python (no Python installation, no internet, no admin
  rights), drivers / DSD-FME / autostart as check boxes, Start menu entries, uninstall (asks about data\).
  The same setup upgrades an installation (data\ stays), also a zip installation of 0.114 or older: it tells
  new installation / upgrade by the folder, says so on its first page, and at an upgrade skips the SDR setup and the
  DSD-FME download (offers a DSD-FME update only when its version changes). A release has only the setup now.
  New version: the page shows it with DOWNLOAD SETUP; nothing is installed from the page any more.
- RADIMCOM.exe: the page in its own window with the RADIMCOM icon (can be pinned to the taskbar), server without a
  console; closing the window keeps the receiver in the tray (decoders, recordings go on), tray menu: open,
  browser, data folder, server log, SDR setup, start / stop / restart server, Exit. A second start only brings the window up.
  Full screen: F11 or the small icon in the corner beside the logo (remembered, orange while on).
  MAIN = the green LED of the logo: under the mouse it turns red ("MAIN OFF"), a click switches RADIMCOM off.
  Resizing the window keeps the aspect ratio of the page (no stretched page).
  Icon: spectrum over a waterfall.
- SDR setup in a window instead of the console (tray menu "SDR setup...", Start menu, end of the installation):
  the connected dongles are dragged onto VFO A-D (or shared), then ppm, upconverter LO and name per VFO;
  IDENTIFY places the dongle you unplug; unique serial numbers for RTL-SDRs with the same number.
- CW decoder rebuilt: soft decisions and a skimmer (docs/decoders/cw.md).
  - Always a skimmer: up to 16 stations at once, SPAN filter or Wide +-3.4 kHz. The CW page is a table of the
    stations with calls and their text; a click opens the whole text, the operator profile and TUNE.
    Stations with calls in the spectrum.
    Sidebands / key clicks of a strong station are not listed as stations.
  - Matched filter, Kalman fading tracker, Viterbi keying decision, beam search over the readings.
  - Learns the operator's timing (bug, straight key, Farnsworth); key type shown.
  - Text coloured by confidence.
  - Measured on synthetic CW: mean character error rate 50 % -> 19 %; Farnsworth 58 % -> 3 %,
    35 WPM at 6 dB 23 % -> 0 %.
  - Block diagram docs/images/cw_decoder.png: where the decoder takes the signal (after AGC+, DC, SPUR;
    before the filter, ALC and DNR) and how it works inside.
- RTTY page like an old terminal, with tuning indicators.
  - Switchable indicator right of the text: CROSS (crossed ellipses, a sharp + = well tuned), WF (mini
    waterfall with the mark / space tones), BARS (tone levels + tuning needle), EYE (eye diagram).
  - Click into the mini waterfall: the decoder looks for the tones only there; AUTO = whole passband.
  - Teletype text with a blinking cursor, unsure characters dim amber, UTC time in the margin.
  - Backlit badges Bd / Hz / NORM / LTRS-FIGS, SNR LED bar, known station label (DWD Pinneberg,
    amateur RTTY segments).
  - KNOWN... list: choose a known RTTY transmission (DWD Pinneberg, amateur segments) and the VFO tunes

  - NO BAUDOT: synchronous / encrypted FSK data is recognised (other speeds tried first) and its
    garbage text is not written.
  - Fix: Auto speed no longer jumps from a speed that decodes well (45.45 -> 50 Bd with noise).

Ver. 0.114
(after the test beta 0.114beta1; many parts by Brano, github.com/brjanicek)
Package fix (13 Nov 2026)
- The first 0.114 package was missing adsb.py, so the server did not start (No module named 'adsb').
  The packages were rebuilt; the package builder now stops when a module imported by the program is not packaged.
- Windows Defender could report the upgrade zip as Trojan:Script/Sabsik.FL.A!ml (a false positive of its
  automatic heuristic). The program no longer starts PowerShell for this: the DSD decoder download falls back
  only to curl.exe of Windows, the upgrade from the page ends leftover decoders through the Windows API, and
  install.bat makes the desktop shortcuts without -ExecutionPolicy Bypass. The .bat files have Windows line endings.
Main Features
- DNR key (AUDIO, right of ALC) for AM/LSB/USB/CW: weak voices out of the noise - the noise between words
  is turned down, speech stays at full level. EXP = expander with a voice detector (speech harmonics stand
  out of the flat HF noise), EXP AUTO (default) sets sensitivity, hold and depth by itself (settles in 2-3 s;
  AUTO off: depth, sensitivity and hold 20-1000 ms by hand, SNR shown in both modes),
  LIM = soft limiter instead of hard clipping (+4 dB with ALC). Parts in SETTINGS -> AUDIO -> DNR.
  Smooth ALC gain (no clicks): SETTINGS -> SDR DONGLE -> ADVANCED, on by default. SETTINGS -> AUDIO
  rearranged; smaller gaps between key groups.
- New look - a front panel like a real rack receiver: one glass over all the displays, the VFO keys (each with its
  CUE key) under their windows, function keys as two-row modules, logo / MONITOR / RECORD in a column at the right,
  band keys across the whole width, rack ears with screws. Keys with an LED window, each key group in its own colour
  (DECODE fuchsia), the lit tab and its accents in the colour of its group. Clock with faint unlit segments and the
  date, faders with a dB scale, level meter with peak hold and CLIP LEDs.
- ISM (by Brano, brjanicek): about twice as many messages - narrow 256 kS/s channels cut out of the dongle
  samples, one rtl_433 each (433.92 + 433.42 MHz, or 868.30 MHz), about 6x less CPU. RAW checkbox: packages
  no decoder read shown as grey rows (pulses, bits, link to triq.org/pdv). One packet read by two decoders
  = one row, repeats merged (xN), SI units.
- SCAN: scanner of memories, ranges and the FM broadcast band. New key SCAN in the MENU group -> SCAN tab. All
  channels in the band of the dongle are measured at once from the spectrum; the tuner moves only between windows.
  What is scanned = four tiles: MEMORY (all / favourites / a group, as chips; each channel in its own mode),
  VISIBLE BAND (the spectrum shown; the tuner is not moved), RANGE FROM-TO-STEP-MODE-BW (presets: airband 8.33 kHz,
  PMR446, 2 m, 70 cm, LPD433, marine VHF, CB; STORE FOUND = found frequencies into the memory group
  "Scan YYYY-MM-DD"); VISIBLE BAND and RANGE in AM or FM only, the MODE keys switch the VFO too. FM BCAST searches
  88-108 MHz in WFM: grid 50 kHz, only the core of each channel is measured and a station must be the strongest point
  +-100 kHz around (checked over 3 blocks), so the VFO lands on its centre; each station is heard LISTEN s (8), then
  the next one up the band; STORE FOUND puts them into the group "FM YYYY-MM-DD", named by their RDS PS.
  Keys: START/STOP; HOLD, SKIP (5 min), LOCK OUT (the channel heard now, until STOP), prev / next only while
  scanning; REC = WAV of each activity with 0.5 s before the signal came back (recordings folder\scan). Settings
  behind the gear key: AUTO SQUELCH (noise floor of each channel + MARGIN), CONTINUE after signal / at once / after
  time, PRIORITY EVERY x s, CARRIER LOCKOUT (30 s - 30 min), PICK next / strongest, KEEP HISTORY days; REC and these
  settings changed while scanning take effect at once. Pages: CHANNELS (per memory SCAN on/off, own SQ, own ASQ
  margin, PRIO, edited in place; x in a row = locked out until STOP, easy to hit while scanning; the channel heard
  has a speaker icon), ACTIVITY (what was heard, with the name and note of a memory at that frequency; CSV export,
  play), HEATMAP (frequency x hour of the day). Both show THIS SCAN: a START of another source / range begins a new
  one, so they start empty; CLR empties them by hand; the history of all VFOs (data\logs\scan_YYYY-MM-DD.csv) is
  kept KEEP HISTORY days (31). Range in the spectrum blue, locked out grey. Decoder and recording of a memory are
  ignored; the decoders of the scanning VFO pause. scanner.py, /api/scan.
- DAB and DSD are modes with their own tabs (by Brano, brjanicek): MODE has a new key DAB (DAB on + DAB tab with the
  DAB+ card); another mode, a band button or a memory that is not DAB turns DAB off. DSD opens its own DSD tab.
  The DAB and DSD pages are gone from DECODERS.
- MEMORIES: modes DAB and DSD (by Brano, brjanicek). A DAB memory has the DAB channel chosen in the form (frequency =
  its centre), recall turns DAB on with it; DAB and DSD have a fixed width. Older memories with a DAB channel are
  read as DAB. IMPORT / EXPORT lists: a DAB row has a dropdown of the DAB channels.
- MEMORIES: simpler channel form (by Brano, brjanicek): name, mode, frequency (or DAB channel) and groups; ADVANCED
  (remembered in the browser) shows the other fields under them.
- DAB now on air in the AD window (in the place of RDS, same colours): DAB / DAB+ tag, station name, SNR (green /
  yellow / red) and the DLS text (artist / song), running when wider than the window. AD priority: 1. errors,
  2. rotor AZ / EL (MONITOR), 3. DAB, 4. RDS.

  MEMORY RECALL and RCTRL MAP, each with a switch to the ROTOR. A click connects / disconnects a source; the rotor

- ROTOR CONTROL tab (new key RCTRL in the key group TRACKING, formerly SAT): a click on the map, on a channel point
  or on a list row turns the station rotor (from any VFO) to that azimuth from the QTH (elevation 0); dashed line =
